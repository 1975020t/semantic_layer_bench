# 用語集・業務ルール（Lahman Baseball Database）

## 業務ルール

1. **stint の合算**: Batting / Pitching は「選手×シーズン×stint」単位。シーズン途中で移籍した選手は同じ年に複数行ある。
   選手のシーズン成績は `playerID, yearID` で合計してから使う（チーム別に見たいときだけ teamID でも分ける）。
2. **率は合計から再計算**: 打率・防御率などの率指標は、行ごとの率を平均してはいけない。
   分子と分母をそれぞれ合計してから割る（例: リーグ打率 = SUM(H) / SUM(AB)）。Pitching.ERA 列は stint 単位なので集計に使わない。
3. **チームと球団**: `teamID` はその年の球団コードで、移転・改称で変わる（エンゼルス: CAL→ANA→LAA、エクスポズ/ナショナルズ: MON→WAS）。
   「球団」「フランチャイズ」を年をまたいで扱うときは `franchID` を使う（エンゼルスは `ANA`、ヤンキースは `NYY`、ナショナルズは `WSN`）。
4. **結合キー**: Batting/Pitching と Teams は `teamID` と `yearID` の両方で結合する（teamID だけで結合すると年の数だけ行が増える）。
   Teams と TeamsFranchises は `franchID` で結合する。
5. **MLB全体**: 「MLB全体」はリーグを絞らずに全行を集計する。「ア・リーグ」= `lgID = 'AL'`、「ナ・リーグ」= `lgID = 'NL'`。
6. **年代**: 「1990年代」= 1990〜1999年。年代は開始年 `(yearID // 10) * 10` で表す。
7. **前年比（増減）**: 当年の値 − 前年の値。
8. **出力**: 選手は `playerID`、チームは `teamID`、球団は `franchID` で答える。数値は丸めない。

## 指標の定義

| 用語 | 定義 |
|---|---|
| 打席（PA） | AB + BB + HBP + SH + SF |
| 規定打席 | シーズンの打席が **502 以上**（162試合 × 3.1） |
| 規定投球回 | シーズンの投球回が **162 以上**（= IPOuts 486 以上）。投球回 = IPOuts / 3 |
| 打率（AVG） | SUM(H) / SUM(AB) |
| 出塁率（OBP） | SUM(H + BB + HBP) / SUM(AB + BB + HBP + SF) |
| 塁打 | H + 2B + 2×3B + 3×HR |
| 長打率（SLG） | SUM(塁打) / SUM(AB) |
| OPS | 出塁率 + 長打率 |
| ISO（長打力） | 長打率 − 打率 = SUM(2B + 2×3B + 3×HR) / SUM(AB) |
| 防御率（ERA） | 27 × SUM(ER) / SUM(IPOuts)（= 自責点 × 9 / 投球回） |
| WHIP | 3 × SUM(BB + H) / SUM(IPOuts)（= (与四球 + 被安打) / 投球回）。Pitching の BB, H を使う |
| 奪三振率（K/9） | 27 × SUM(SO) / SUM(IPOuts) |
| 勝率 | SUM(W) / SUM(W + L) |
| 1試合あたり得点 | SUM(R) / SUM(G)（Teams） |

## 曖昧な表現の解釈（この分析での約束）

- **最強打者**: 規定打席に到達した打者のうち **OPS が最も高い** 打者。
- **安定した投手**: 規定投球回に到達した投手のうち **WHIP が低い** 投手（低いほど安定）。
- **成功した球団**: 期間通算の **レギュラーシーズン勝率** が最も高いフランチャイズ（ポストシーズンの成績ではない）。
- **長打力 / パワーヒッター**: **ISO** が高い打者。複数年の期間で比べるときは、期間通算の打席が **3000 以上** の打者に限る。
- **トップN / 上位N**: 指標の良い順（率指標は防御率・WHIP は低い順、それ以外は高い順）に N 件。
